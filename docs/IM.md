# 在微信、企业微信、飞书里给 agent 派任务

用 [dsh-im](https://github.com/xmanrui/dsh-im) 插件（3300 多星）。它在 DSH 里面运行：聊天软件里收到的消息，直接变成 DSH 的一次任务，回答发回聊天软件。它调模型走的是 DSH 自己的接口，所以照样经 dsh-llm-ferry 和你的服务端，切片也照常。

已测：同一个 DSH 里装 dsh-llm-ferry 和 dsh-im 5.10.0，网页版正常启动，"IM机器人"页面列出全部渠道，模型选择框里是 Ferry 的模型，对话走 Ferry 服务端。扫码绑定需要你自己的账号，还没实测。

## 支持哪些

| 渠道 | 怎么接 | 怎么连 |
|---|---|---|
| 微信 | 手机微信扫码 | 腾讯 iLink 长轮询 |
| 企业微信 | 企业微信 App 扫码建智能机器人，或填 Bot ID + Secret | 官方 WebSocket 长连接 |
| 飞书 | 扫码建机器人，或填 App ID + Secret | 长连接 |
| 钉钉 | 扫码建机器人，或填 Client ID + Secret | Stream 长连接 |
| QQ、Slack、Telegram、Discord、WhatsApp 等 | 见插件说明 | |

都是电脑主动连出去，不需要公网地址，也不用开端口。

## 装

桌面版：左侧"插件"→"添加插件"，填 `@xmanrui/dsh-im`，装完启用，重启桌面版。

命令行版：

```powershell
dsh plugin --profile web add -w @xmanrui/dsh-im
```

重启 `dsh web` 后，左侧多一个"IM机器人"，选渠道，按页面引导扫码。

## 在工作电脑上用之前想清楚

- 内容会经过聊天软件的服务器：你发的任务、agent 的回答（可能含文件内容）都经腾讯、飞书或钉钉的服务器。公司对工作资料有规定的，以规定为准；企业微信、飞书若是公司自己的租户，一般比个人微信合适。
- 能给机器人发消息的人，就能让工作电脑上的 agent 读写文件、跑命令。扫码新建的飞书和 QQ 机器人默认谁都能用，一定要在机器人的访问设置里设白名单，只留你自己。
- 保留审批：DSH 的访问模式用默认的"工作区内修改"，危险操作仍会请你确认（dsh-im 会把确认问题发到聊天里）。
- 公司网络可能不放行这些聊天软件的长连接。飞书可以走 `HTTPS_PROXY` 代理（dsh-im 说明里有）。
- 电脑要开着、DSH 要运行，消息才有人接。

## 能做什么

- 路上用手机发："把今天 RAN2 新上传的文稿列出来，挑和 RRC 有关的写三句话摘要"，到了公司打开电脑看结果。
- 配合 DSH 的定时任务：每天早上自动跑一遍，结果推到你的企业微信或飞书。
- 群里 @ 机器人问规范条款，它在工作电脑上查本地的规范文件再回答。
